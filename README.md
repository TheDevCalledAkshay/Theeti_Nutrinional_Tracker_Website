# Theeti

WEBSITE LINK : https://thedevcalledakshay.github.io/Theeti_Nutrinional_Tracker_Website/

**Eat. Train. Repeat. Simple. No bullshit.**

Theeti is a personal nutrition tracking web app built to make tracking daily food intake simple, fast, and accessible.

No complicated setup. Just enter what you ate and let Theeti do the math.

## Features

* Track daily food intake.
* Calculate calories and nutritional values.
* View protein, carbohydrates, fats, and fiber.
* Search food items using a local food database.
* Optional USDA FoodData Central API integration for additional food information.
* Simple and user-friendly interface.
* Designed with offline use in mind.

## Tech Stack

* **HTML5** — Website structure.
* **CSS3** — Styling and responsive design.
* **JavaScript** — Food calculations, interactions, and application logic.
* **USDA FoodData Central API** — Additional food nutrition information.
